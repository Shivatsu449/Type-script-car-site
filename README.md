# NOIR MACHINES

Автомобильный каталог с тёмным интерфейсом, поиском, фильтрами и отдельными страницами моделей. Создан на **React + TypeScript + Vite**.

## Возможности

- Каталог автомобилей 14 марок: Lamborghini, Ferrari, McLaren, Porsche, Aston Martin, Mercedes-AMG, Audi, Dodge, Chevrolet, Ford, Bugatti, Koenigsegg, Pagani и Rimac.
- Поиск и фильтрация по сегментам.
- Страница каждой машины: фотографии, характеристики и редакционные блоки.
- Загрузка фотографий и справочной информации через Wikipedia / Wikimedia.
- Постепенная загрузка обложек, очередь запросов, повторные попытки и кэширование.
- Адаптивная вёрстка и анимации Framer Motion.

## Запуск на Windows

1. Установите **Node.js LTS** с [официального сайта](https://nodejs.org/en/download). Рекомендуется поддерживаемая LTS-версия 22 или новее. npm устанавливается вместе с Node.js.
2. Скачайте проект через **Code → Download ZIP** или GitHub Desktop и распакуйте его.
3. Откройте папку с `package.json`.
4. Дважды щёлкните `start.bat`. При первом запуске он установит зависимости, затем запустит сервер.
5. Откройте адрес, показанный в окне сервера: обычно **http://localhost:5173/**.

Окно сервера должно оставаться открытым, пока вы пользуетесь сайтом. Для остановки нажмите **Ctrl+C**. Docker для этого проекта не нужен.

### Запуск командами

В Проводнике откройте папку проекта, в адресной строке введите `powershell` и нажмите Enter. Выполните:

```powershell
npm.cmd ci
npm.cmd run dev
```

`npm.cmd` позволяет запускать npm в PowerShell без изменения политики выполнения скриптов. Если Node.js только что установлен, заново откройте терминал.

### Linux / macOS

Установите Node.js LTS, затем в папке проекта выполните:

```sh
sh start.sh
```

Либо используйте `npm ci` и `npm run dev`.

## Проверка сборки

```powershell
npm.cmd run build
npm.cmd run preview
```

Готовые файлы появятся в `dist/`. Локальный предпросмотр обычно доступен по адресу **http://localhost:4173/**; точный адрес указан в терминале. `preview` предназначен для проверки сборки на своём компьютере.

Открытие `index.html` двойным щелчком не запускает этот React-проект: используйте сервер разработки или собранный сайт.

```text
NoirMachines/
├── src/
│   ├── components/      # Карточки, фильтры, галерея и другие блоки
│   ├── data/cars.ts     # Каталог и генерация демонстрационных данных
│   ├── pages/           # Каталог и страница автомобиля
│   ├── services/        # Работа с Wikipedia и Wikimedia
│   ├── styles/          # Оформление
│   ├── App.tsx          # Маршруты
│   └── main.tsx         # Точка входа React
├── index.html
├── package.json
├── package-lock.json   # Зафиксированные версии зависимостей
├── vite.config.ts
├── tsconfig*.json
```

`node_modules/` и `dist/` не загружаются в GitHub: зависимости устанавливаются через `npm ci`, сборка создаётся через `npm run build`.

## Фотографии и данные

Для загрузки фотографий и справочных материалов нужен интернет. Изображения могут появляться постепенно; при недоступности Wikipedia/Wikimedia или ограничении запросов фотографии могут не загрузиться. Изображения не входят в этот архив.

Часть технических характеристик и редакционных данных генерируется кодом как демонстрационное наполнение. Эти значения не следует считать проверенными заводскими характеристиками конкретных моделей.

У фотографий собственные условия использования. Интерфейс выводит сведения об источнике и лицензии, когда они доступны из API; наличие ссылки на Wikipedia само по себе не подтверждает конкретную лицензию фотографии.

## Публикация сайта

В GitHub можно хранить исходники проекта. Для сайта по публичной ссылке нужно сначала выполнить сборку и разместить содержимое `dist/` на статическом хостинге.

Проект использует `BrowserRouter`: хостинг должен отдавать `index.html` для адресов вида `/car/...`, чтобы прямые ссылки и обновление страницы работали. Для GitHub Pages в подпапке репозитория дополнительно потребуется настроить базовый путь Vite и маршрутизацию. Простого выбора ветки с исходниками в Pages недостаточно.

Официальная инструкция: [публикация Vite-проекта](https://vite.dev/guide/static-deploy.html).
